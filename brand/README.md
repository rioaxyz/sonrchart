# Brand assets

The sonrchart mark is Sonr's sonar rings with candlesticks where Sonr's line
was: the same family as the scanner, but the chart. Green is up, red is down.

| File | Use |
| --- | --- |
| `sonrchart-icon.svg`, `png/sonrchart-icon-*.png` | App icon, npm and GitHub avatars (1024 down to 32 px) |
| `sonrchart-logo.svg`, `png/sonrchart-logo-*w.png` | Icon and wordmark, for dark backgrounds |
| `sonrchart-logo-on-light.svg`, `png/sonrchart-logo-on-light-*w.png` | Icon and wordmark, for light backgrounds |
| `favicon.ico` | 16, 32 and 48 px favicon |
| `png/sonrchart-social-1280x640.png` | GitHub social preview and link cards |

Colors: ground `#0E1216`; rings `#14302A`, `#1B5444`, `#4BA98A`; up `#35C98D`;
down `#FF6A76`. The wordmark is "sonr" in Archivo Black and "chart" in IBM Plex
Mono Medium, outlined so the SVGs need no fonts.
